# Primer Sistema Cuántico

Este proyecto fue desarrollado por **Juan Felipe Arango Hidalgo**, estudiante de **Ingeniería de Sistemas** en la **Escuela Colombiana de Ingeniería Julio Garavito**, como parte de la asignatura **Ciencias y Tecnología (CNYT)**.

## Descripción

Este proyecto tiene como objetivo implementar y explorar los conceptos básicos de los sistemas cuánticos, utilizando la simulación computacional para ilustrar cómo se comportan ciertos elementos fundamentales de la mecánica cuántica. Se enfoca principalmente en los conceptos de qubits, superposición, entrelazamiento y operaciones cuánticas, utilizando representaciones matriciales y vectores complejos.

## Contenido del Cuaderno

El archivo principal es el cuaderno `Primer_Sistema_Cuantico.ipynb`, que está dividido en las siguientes secciones:

1. **Introducción a la Computación Cuántica**  
   - Explicación de los principios básicos de la computación cuántica, incluyendo los qubits y su diferencia con los bits clásicos.
   - Conceptos de superposición cuántica y cómo un qubit puede estar en múltiples estados simultáneamente.

2. **Representación de Qubits**  
   - Fundamentos matemáticos de los qubits utilizando vectores y matrices.
   - Representación de qubits como vectores en el espacio de Hilbert y exploración de los estados |0⟩ y |1⟩.
   - Ejemplos prácticos de creación y manipulación de qubits.

3. **Operaciones Cuánticas**  
   - Introducción a puertas cuánticas como Hadamard, Pauli-X, Pauli-Z y cómo afectan el estado de los qubits.
   - Ejemplos prácticos de operaciones mediante la multiplicación de matrices.

4. **Simulación de Sistemas Cuánticos**  
   - Simulación de sistemas con múltiples qubits y exploración del entrelazamiento cuántico.
   - Implementación de operaciones de entrelazamiento y medición del estado de sistemas cuánticos.

5. **Algoritmos Cuánticos Básicos**  
   - Implementación de algoritmos como Grover y Deutsch-Jozsa.
   - Explicación paso a paso del funcionamiento y la eficiencia de estos algoritmos.

6. **Visualización de Resultados**  
   - Uso de `matplotlib` para visualizar estados cuánticos y probabilidades resultantes de las simulaciones.

## Requisitos

Para ejecutar este proyecto, asegúrate de tener instaladas las siguientes dependencias:

- **Python 3.x**
- **Jupyter Notebook**
- Librerías de Python:
  - `numpy` (manejo de matrices y números complejos).
  - `matplotlib` (visualización de datos).

Instala las dependencias ejecutando:

```bash
pip install numpy matplotlib
```
